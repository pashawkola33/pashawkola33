# Pavlo Sushkov

I study Economic Informatics at the Bucharest University of Economic Studies (ASE). I build backend services and practical applications, with a focus on APIs, data processing, and automation.

My main tools are **Java, Spring Boot, PostgreSQL, TypeScript, and Docker**. I care about clear data models, reliable integrations, and testing beyond the happy path.

## Projects

**[JobPilot](https://github.com/pashawkola33/JobPilot)**  
A job discovery and tracking service built with Java, Spring Boot, PostgreSQL, and Telegram. It collects listings from public job boards, deduplicates them, matches vacancies to candidate preferences, and delivers notifications. The deployed version is private; multi-user functionality is in development.

**[MeBuc](https://github.com/pashawkola33/MeBuc)**  
An offline-first Bucharest Metro route planner built with Expo, React Native, and TypeScript. It supports transfer-aware routes, an interactive network map, and three languages.

**[nexusinvest](https://github.com/pashawkola33/nexusinvest)**  
An investment platform simulation with a Spring Boot backend and React/TypeScript frontend, covering market data, portfolios, and trading workflows.
